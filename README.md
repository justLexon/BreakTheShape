Break The Shape is a mobile tap and idle game built in Unity. The player taps a central shape to deal damage, break it, earn coins, and purchase upgrades. Shapes increase in health as you progress. Materials increase rewards and shape health, and new shape packs can be unlocked through gameplay.

The game includes tap damage, idle damage, shape health scaling, materials with coin multipliers, tools for increasing damage, a shape pack system with an inventory menu, randomized textures using sprite atlases, and data saving through PlayerPrefs.

It is built using Unity with C#, Shader Graph, sprite atlases, and Unity UI.

How to play: tap the shape to deal damage, break the shape to earn coins, buy upgrades to increase power, unlock new materials and shapes, and continue progressing.

The project structure contains folders for scripts, shaders, prefabs, art, and scenes.
